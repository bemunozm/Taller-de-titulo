# =============================================================================
# lpr — runtime dependencies (pinned for reproducible edge deploys)
# =============================================================================
# Todas las versiones están fijadas (== / ~=) para que `pip install -r
# requirements.txt` produzca el mismo entorno en una Raspberry Pi limpia.
# Mantener sincronizado con la lista `dependencies` de pyproject.toml.
#
# --- ARM / Raspberry Pi (aarch64) --------------------------------------------
# En RPi5 / ARM64, `torch` y `torchvision` suelen necesitar un índice de wheels
# aparte (o los paquetes del sistema). Si `pip install torch` falla en la Pi,
# instalar torch/torchvision primero desde el índice oficial, por ejemplo:
#   pip install torch==2.8.0 torchvision==0.23.0 \
#       --index-url https://download.pytorch.org/whl/cpu
# y luego `pip install -r requirements.txt` para el resto.
#
# --- Deuda técnica (Fase 5) --------------------------------------------------
# La meta a futuro es SACAR torch/torchvision del runtime a favor de ONNX
# (ultralytics exporta a .onnx y fast-plate-ocr ya corre sobre onnxruntime).
# Eso elimina ~cientos de MB de dependencias nativas en ARM.
# =============================================================================
